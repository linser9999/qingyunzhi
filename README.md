## 🚀 快速开始

```powershell
# 1. 安装依赖
npm install

# 2. 本地开发
npm run dev        # → http://localhost:5173

# 3. 测试
npm test           # 25 项单元测试

# 4. 生产构建
npm run build      # → dist/（含 PWA）
```

> 首次打开自动载入示例数据，**无需配置即可体验**。

## ☁️ 配置 GitHub 云同步（跨设备）

1. GitHub 创建仓库（如 `qingyunzhi`），生成 Personal Access Token（勾选 `repo`）
2. 应用「设置 → GitHub 云同步」填入 Token / 用户名 / 仓库名 → 测试连接 → 保存并同步
3. 数据自动写入仓库 `data/user-data.json`；换设备填同一配置即拉取相同数据
4. Token 仅存于本机浏览器 localStorage，请勿提交到仓库

## 📦 部署到 GitHub Pages

```powershell
# 推送源码（main 分支，含 data/）
git init && git add -A && git commit -m "init"
git remote add origin <你的仓库地址>
git push -u origin main

# 部署静态站（gh-pages 分支）
$env:GHP_REPO = "<你的仓库地址>"
$env:GHP_BASE  = "/"          # 子路径填 "/仓库名/"
npm run deploy
```

然后在 GitHub 仓库 Settings → Pages 选择 `gh-pages` / `root` 分支即可。
详细步骤见 `docs/04-开发者文档.md`。

## 📐 技术栈

- **前端**：Vue 3 + Vite + Pinia + Vue Router（hash 模式）
- **图表**：ECharts（按需引入）
- **数据**：GitHub REST API（PAT 鉴权）+ localStorage 缓存，service 抽象层可替换 Supabase
- **PWA**：vite-plugin-pwa，离线可查看、联网自动同步
- **样式**：自定义古风主题 CSS（米色/淡青/浅粉 + 楷体标题 + 祥云纸鸢动画）
