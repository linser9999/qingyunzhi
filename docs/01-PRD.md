# 《青云志 · 人生进度簿》产品需求文档（PRD）

> 版本 v1.0.0 ｜ 需求分析师产出 ｜ 2026-08-29

---

## 1. 产品概述

### 1.1 一句话定位
一款「童真动画古风」风格的个人成长与财务追踪 Web 应用，帮助用户可视化记录目标、计划、消费、读书、学习、复盘等数据，一步步走向「净资产 100 万 → 财富自由」。

### 1.2 背景
用户为计算机专业大四学生，未来 6 年目标是净资产 100 万，希望在 35-40 岁实现财富自由。需要一款**单用户、跨设备、数据一致**的工具承载全程记录与复盘。

### 1.3 目标用户
- 单用户使用，无多用户 / 权限系统
- 同时通过电脑浏览器与手机浏览器访问，数据完全一致

### 1.4 非目标
- 不做多人协作、不做社交分享、不做复杂权限
- 不做独立后端服务器（使用 GitHub API 作为数据读写接口）

## 2. 技术约束（用户点名，不可替换）
| 项 | 要求 |
|---|---|
| 前端 | Vue 3 + Vite + Pinia（选择理由：生态成熟、响应式状态管理契合单用户全量数据、路由/懒加载适合多页面应用） |
| 图表 | ECharts（按需引入，减小包体） |
| 数据后端 | GitHub REST API 读写仓库内 `data/user-data.json` |
| 身份 | GitHub PAT，存 localStorage，经 HTTP 请求头调用 |

| PWA | 可添加至手机主屏幕，离线查看缓存数据，联网自动同步 |
| 扩展 | 数据层抽象为 service，预留替换 Supabase 等云数据库的接口 |

## 3. 功能需求

### 3.1 目标管理
- 创建长期 / 年度 / 季度 / 月度 / 周度 / 每日目标
- 字段：名称、描述、开始 / 截止日期、目标数值、当前数值、单位、进度模式（自动/手动）、状态（进行中/暂停/达成/放弃）
- 目标可拆解（parentId 关联子目标），子目标递归展示
- 目标内含里程碑（名称、目标数值、日期、是否达成），可勾选
- 进度可视化：进度条 + 数值进度 + 时间流逝占比 + 印章达成百分比

### 3.2 计划制定
- 支持一次性 / 每日 / 每周 / 每月 / 每季度 / 每年计划
- 字段：任务名、所属目标、起止日期、起止时间、优先级（高/中/低）、状态（未开始/进行中/已完成/已放弃）、完成度
- 周期重复：每日 / 每周（选星期）/ 每月
- 拖拽排序（HTML5 drag）+ 上移/下移兜底
- 列表筛选（状态 / 周期 / 关键词）

### 3.3 每日记录与打卡
- 按日期记录：完成任务（多行）、学习时长、运动、读了什么书、心情（1-5）、小结、反思、自定义标签
- 打卡项（今日已定投、今日已刷题…），可勾选完成
- 历史记录列表

### 3.4 消费与财务追踪
- 消费记录：金额、日期、时间、类别（餐饮/房租/交通/学习/娱乐/医疗/人情/其他）、支付方式（微信/支付宝/银行卡/现金）、消费模式（必需/可选/冲动/投资）、备注
- 收入记录：金额、日期、类型（工资/副业/理财收益/其他）、备注
- 类别与模式可自定义增加
- 月度汇总：月总支出、月总收入、结余、预算执行
- 可视化：支出结构饼图、类别×模式堆叠柱状图、近 6 月收支折线图
- CSV 导出

### 3.5 读书清单与学习记录
- 书目：书名、作者、起止日期、读书笔记、评分（1-5）、状态（在读/已读/放弃）、标签
- 学习记录：日期、内容、时长、笔记、链接、标签
- 搜索与分类筛选；累计学习时长；按学科汇总

### 3.6 复盘总结系统
- 每日 / 每周 / 每月 / 季度 / 年度复盘
- 富文本：支持 Markdown（标题/列表/表格/引用/代码块/链接），实时预览
- **自动生成**：根据真实数据生成草稿（本阶段支出、收入、结余、学习时长、读书、计划完成率等）
- 列表视图 + 时间线视图

### 3.7 路线图与里程碑
- 从当前到目标年龄的阶段规划（秋招 → 毕业入职 → 跳槽涨薪 → 副业起步 → 资产积累 → 财富自由）
- 每阶段：起止时间、目标状态、关键行动（标签）、是否达成
- 时间轴可视化 + 拖拽调整顺序 + 整体达成进度

### 3.8 存款与资产追踪
- 按月记录现金 / 基金 / 股票 / 其他
- 净资产曲线（含目标线对比）、资产构成堆叠图
- 年化增长率、距目标差额、整体进度

### 3.9 数据统计与分析
- 自定义时间范围（快捷：近7天/本月/本季/本年/近30天/全部 + 手动起止）
- 指标：支出、收入、结余、学习时长、读书、任务完成率
- 交叉分析：冲动消费工作日 vs 周末占比；分类×星期；副业收入×学习时长（按月散点）
- 月度/季度/年度报告：导出 Markdown / 打印另存为 PDF

### 3.10 提醒与通知
- 每日 / 每周定时提醒（浏览器 Notification）
- 目标 deadline 前 7 天提醒
- 预算超支提醒
- 配置存本地（不上传云端）

### 3.11 人生进度总览（仪表盘）
- 6 年目标进度（大进度条 + 印章）
- 当前净资产、本月结余、累计学习、读书数量、任务完成率
- 本月支出结构饼图、净资产趋势
- 近期计划、今日记录快照

## 4. 数据存储与同步策略
- 单一 JSON 文件 `data/user-data.json`（结构见《数据字典》）
- **读**：本地缓存立即可用 → 尝试拉取 GitHub → 离线回退缓存 → 无缓存则载入示例数据
- **写**：变更后 1.2s debounce 合并为一次 PUT（批量提交机制，规避限流）→ 写入前先落本地缓存
- **冲突**：PUT 遇 409 自动拉远端按 id 合并（本地优先）后重推
- PAT 仅存浏览器 localStorage；API 配额以 5000 次/小时 为主，配合 debounce 足够日常使用

## 6. 验收标准
1. 电脑与手机浏览器均可访问，布局自适应，数据实时同步
2. 目标、计划、记录、消费、读书、复盘、资产、仪表盘全部可用
3. 数据保存到 GitHub 后，另一设备可拉到相同数据（以数据文件为准）
4. 界面符合「童真动画古风」，动画流畅
5. 代码结构清晰、注释完整、可二次开发
6. 提供本地运行与 GitHub Pages 部署步骤

## 8. 设计规范（UI/UX）
- **色调**：浅米色 `#fbf3e4` 主背景，淡青 `#5b8c85`、浅粉 `#e0a1a1` 点缀，朱砂/鎏金点缀，暖色柔和
- **字体**：标题使用楷体/行楷（`Kaiti SC/STKaiti/KaiTi` 等），正文系统无衬线
- **插画**：祥云飘过动画、纸鸢飞入、灯笼轻晃、漂浮元素；纸鸢为品牌图标
- **组件**：卡片圆角 18px、轻阴影、渐变按钮、点击弹跳动画、页面切换过渡
- **氛围**：水墨山水渐变背景 + 纸鸢/祥云/灯笼 SVG 装饰
