# 《青云志 · 人生进度簿》数据字典

> 数据层开发产出 ｜ 数据存储于 GitHub 仓库 `data/user-data.json`，单文件 JSON。

---

## 0. 顶层结构

```json
{
  "user": { },
  "goals": [],
  "plans": [],
  "dailyRecords": [],
  "consumptions": [],
  "incomes": [],
  "assets": [],
  "books": [],
  "learnings": [],
  "reviews": [],
  "milestones": []
}
```

**通用约定**
- 所有对象含 `id`（字符串，唯一，如 `g-xxx`）与 `createdAt`（ISO 时间戳）
- 更新操作会附加 `updatedAt`
- 金额单位统一为「元」，数值类型用 Number
- 日期统一 `YYYY-MM-DD`；月份键 `YYYY-MM`；时间 `HH:mm`

---

## 1. user（用户资料）

| 字段 | 类型 | 说明 |
|---|---|---|
| name | string | 昵称，默认"追梦人" |
| birthday | string | 生日，YYYY-MM-DD |
| targetAge | number | 目标年龄（财富自由），默认 40 |
| baselineSalary | number | 基准月薪 |
| monthlyBudget | number | 月度总预算（元） |
| customCategories | string[] | 自定义消费类别 |
| customModes | string[] | 自定义消费模式 |
| createdAt | string | 创建时间 |

---

## 2. goals（目标）

| 字段 | 类型 | 说明 |
|---|---|---|
| id / createdAt | - | 通用 |
| name | string | 目标名称 |

| type | string | 长期/年度/季度/月度/周度/每日 |

**Milestone（里程碑）**
| 字段 | 类型 | 说明 |

## 12. 本地存储（浏览器 localStorage，不上传 GitHub）
| key | 内容 |
|---|---|
| `qyz_data_v1` | 最近一次成功的数据快照（离线可查） |
| `qyz_meta_v1` | `{ sha, syncedAt, source }` 同步元信息 |
| `qyz_gh_cfg_v1` | `{ token, owner, repo, branch, path }` GitHub 配置（PAT 仅存本地） |
| `qyz_settings_v1` | 提醒等本地偏好 |
| `qyz_ui_v1` | UI 偏好 |

---

## 13. 数据流
```
视图操作 → dataStore（Pinia）→ 内存 data
                              ├─ 立即写 localStorage（离线可用）
                              └─ debounce 1.2s → GitHubService PUT（批量合并）
                                              ├─ 成功：更新 sha + 缓存
                                              ├─ 409 冲突：拉远端合并重推
                                              └─ 失败：保留本地，状态提示重试
```
