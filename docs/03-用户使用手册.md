## 1. 快速开始

1. **打开应用**：访问你的 GitHub Pages 地址（如 `https://用户名.github.io/仓库名/`），或本地 `npm run dev` 后访问 `http://localhost:5173`
2. **无需配置即可体验**：首次打开会载入一组示例数据，可直接浏览所有功能
3. **登录云同步（可选但推荐）**：进入「设置 → GitHub 云同步」
   - 填写 Personal Access Token（需 `repo` 权限）、仓库用户名、仓库名
   - 点击「测试连接」→「保存并同步」
   - 之后所有数据自动同步到该仓库的 `data/user-data.json`
4. **多设备**：在另一台设备同样填入同一仓库配置，即可拉到相同数据

> 提示：数据仅存于你自己的 GitHub 仓库，Token 只保存在本机浏览器，不会上传。

## 2. 功能模块使用说明

### 2.1 人生总览（仪表盘）
首页展示六大核心指标：**当前净资产 / 本月结余 / 累计学习 / 读书与任务完成率**，以及六年目标进度、本月支出结构、净资产趋势。
- 点击「今日打卡」快速进入每日记录
- 底部同步条显示当前同步状态，点击可立即保存

### 2.2 目标管理
- 点击「＋ 新建目标」，填写名称、类型（长期/年度/季度/月度/周度/每日）、起止日期、目标金额
- **拆解子目标**：编辑目标时在「关联父目标」选择一个父目标，即成为其子目标（会递归展示）
- 添加里程碑：目标内点击「＋ 添加里程碑」，点里程碑可勾选达成
- 状态可「暂停/继续」，进度条同时显示数值进度与时间流逝

### 2.3 计划制定
- 「＋ 新建计划」创建任务，支持一次性/每日/每周/每月
- 每周重复可选择星期几
- **排序**：直接拖动任务行即可调整顺序；手机端可用 ↑/↓ 按钮
- 点击状态标签可循环切换：未开始 → 进行中 → 已完成

### 2.4 每日记录
- 顶部选择日期（默认今天），填写完成任务、学习时长、运动、心情、反思、小结
- **打卡**：点预置打卡项切换完成（今日已定投、今日已刷题等）
- 右侧「记录史册」展示历史记录

### 2.5 消费与财务
- 「＋ 记支出」：金额、类别、支付方式、消费模式（**建议如实标注「冲动」**，便于后续分析）
- 「＋ 记收入」：工资/副业/理财收益等
- 顶部可切换月份，查看月总支出、结余、预算执行
- 三个图表：支出结构饼图、类别×模式、近 6 月收支趋势
- 「⚙ 自定义类别」可增加类别与模式、设置月度总预算
- 「导出 CSV」可将本月明细导出为表格

### 2.6 读书清单
- 「＋ 添加书目」，记录书名、作者、状态、评分、笔记、标签
- 点状态标签切换：在读 → 已读 → 在读
- 支持按书名/作者搜索、按状态/标签筛选

### 2.7 学习记录
- 「＋ 记录学习」：内容、时长、笔记、链接
- 左侧展示累计学习时长与学科分布，右侧为明细列表

### 2.8 复盘总结
- 「＋ 新建复盘」，选择类型（每日/每周/每月/季度/年度）
- 点击「✨ 根据数据自动生成草稿」，系统会根据真实数据生成一段带统计的 Markdown 草稿，你再补充具体内容
- 正文支持 Markdown（标题、列表、表格、引用），右侧实时预览
- 可切换「列表 / 时间线」两种视图

### 2.9 路线图
- 展示「秋招 → 毕业入职 → 跳槽涨薪 → 副业起步 → 资产积累 → 财富自由」的时间轴
- 每个阶段可「标记达成」，可拖拽调整顺序，可编辑关键行动

### 2.10 资产追踪
- 每月点「＋ 记录本月资产」，填现金/基金/股票/其他，自动计算净资产
- 净资产曲线会叠加「目标线」；下方显示年化增长率、距目标差额
- 同月重复录入会自动更新该月快照

### 2.11 数据统计
- 选择统计区间（本月/本季/本年/近30天/全部，或手动起止）
- 查看支出结构、分类×星期、**冲动消费工作日 vs 周末**、副业收入×学习时长散点
- 「导出 Markdown 报告」生成报告文件；「打印/存为 PDF」通过浏览器另存为 PDF

### 2.12 设置
- **个人资料**：昵称、生日、目标年龄、基准月薪、月度预算
- **GitHub 云同步**：见「快速开始」
- **数据管理**：导出 JSON 备份 / 导入 JSON / 载入示例 / 清空数据
- **提醒通知**：开启浏览器通知、设置每日/每周提醒时间、目标到期提醒、预算超支提醒

## 3. 常见问题（FAQ）

**Q1：不配置 GitHub 能用吗？**
可以。默认本地模式，数据保存在浏览器 localStorage。但换设备/清缓存会丢失，建议配置云同步。

**Q2：Token 安全吗？**
Token 仅存于你的浏览器 localStorage，通过 HTTPS 请求头发送到 GitHub。请勿把 Token 提交到任何仓库，建议使用最小权限的 Fine-grained Token（仅该仓库、contents 读写）。

**Q3：为什么偶尔提示「同步失败」？**
多为网络波动或 GitHub 限流。数据已保存在本地，点击底部同步条「重试」即可；409 冲突会自动合并。

**Q4：如何离线使用？**
PWA 已启用：首次在线打开后，添加到手机主屏幕，之后离线也能查看缓存数据，联网自动同步。

**Q5：如何彻底删除示例数据？**
「设置 → 数据管理 → 清空全部数据」；或在 GitHub 仓库删除 `data/user-data.json` 后再点「拉取」。

**Q6：换了台电脑/手机如何找回数据？**
在设置里填入同一个 GitHub 仓库配置并保存，应用会自动拉取云端数据。
